
### Определение

$(\mathcal X, \mathscr M, \mu)$ — пространство с σ-конечной мерой

$\big\{f_n: (\mathcal X, \mathscr M) \rightarrow (\Bbb R, \mathfrak B(\Bbb R))\big\}_{n \in \Bbb N}$ — последовательность измеримых функций
$f: (\mathcal X, \mathscr M) \rightarrow (\Bbb R, \mathfrak B(\Bbb R))$ — измеримая


Будем говорить, что $f_n$ сходятся к $f$ по мере $\mu$ (или по вероятности), и писать

$$f_n \mathop{\longrightarrow}\limits^{\mu \ } f$$
если

$$\mu \big(\{x: |f_n(x) - f(x)| \ge \varepsilon \} \big) \mathop{\longrightarrow}\limits_{n \to \infty}0 \quad \forall \varepsilon > 0$$


### Теорема

Предел по мере единственный почти всюду. 

$$f_n \mathop{\longrightarrow}\limits^{\mu \ } f_1 \quad f_n \mathop{\longrightarrow}\limits^{\mu \ } f_2$$
$$\Downarrow$$
$$\mu \big( \big \{ x \in \mathcal X: f_1(x) \ne f_2(x)  \big \} \big) = 0$$

##### Доказательство

Неравенство треугольника:


$$\forall \varepsilon > 0 \quad \{x \in \mathcal X : \lvert f_1(x) - f_2(x)\rvert \ge \varepsilon \} \subset$$
$$\subset \{x \in \mathcal X : \lvert f_1(x) - f_n(x)\rvert \ge \frac{\varepsilon}{2} \} \ \cup \ \{x \in \mathcal X : \lvert f_2(x) - f_n(x)\rvert \ge \frac{\varepsilon}{2} \}$$
$$\Downarrow$$

$$\forall \varepsilon > 0 \quad \mu \big( \{x \in \mathcal X : \lvert f_1(x) - f_2(x)\rvert \ge \varepsilon \} \big) \le$$
$$\le \mu \big(\{x: \lvert f_1(x) - f_n(x) \rvert \ge \frac{\varepsilon}{2} \} \big) \ + \ \mu \big(\{x: \lvert f_2(x) - f_n(x) \rvert \ge \frac{\varepsilon}{2} \} \big)$$


Из определения сходимости по мере следует, что сумму мер из правой части неравенства треугольника можно сделать сколько угодно близкой к нулю, выбрав достаточно большое значение индекса $n$


$$\mu \big(\{x: \lvert f_1(x) - f_n(x) \rvert \ge \frac{\varepsilon}{2} \} \big) \mathop{\longrightarrow}\limits_{n \to \infty}0 \quad \forall  > 0$$
$$\mu \big(\{x: \lvert f_2(x) - f_n(x) \rvert \ge \frac{\varepsilon}{2} \} \big) \mathop{\longrightarrow}\limits_{n \to \infty}0 \quad \forall  > 0$$


В то время как левая часть неравенства треугольника не зависит от $n$, следовательно


$$\mu \big( \{x \in \mathcal X : \lvert f_1(x) - f_2(x)\rvert \ge \varepsilon \} \big)=0$$



### Сходимость по мере и арифметика

1\. Сумма

$$f_n \mathop{\longrightarrow}\limits^{\mu \ } f \quad g_n \mathop{\longrightarrow}\limits^{\mu \ } g$$
$$\Downarrow$$
$$f_n + g_n \mathop{\longrightarrow}\limits^{\mu \ } f+g$$


Неравенство треугольника:


$$\forall \varepsilon > 0 \quad \{x \in \mathcal X : \lvert f_n(x) + g_n(x) - f(x) -g(x)\rvert \ge \varepsilon \} \subset$$
$$\subset \{x \in \mathcal X : \lvert f_n(x) - f(x)\rvert \ge \frac{\varepsilon}{2} \} \ \cup \ \{x \in \mathcal X : \lvert g_n(x) - g(x)\rvert \ge \frac{\varepsilon}{2} \}$$
$$\Downarrow$$

$$\forall \varepsilon > 0 \quad \mu \big( \{x \in \mathcal X : \lvert f_n(x) + g_n(x) - f(x) -g(x)\rvert \ge \varepsilon \} \big) \le$$
$$\le \mu \big(\{x: \lvert f_n(x) - f(x) \rvert \ge \frac{\varepsilon}{2} \} \big) \ + \ \mu \big(\{x: \lvert g_n(x) - g(x) \rvert \ge \frac{\varepsilon}{2} \} \big)$$
$$\to 0 + 0 \to 0$$


2\. Произведение

$$f_n \mathop{\longrightarrow}\limits^{\mu \ } f \quad g_n \mathop{\longrightarrow}\limits^{\mu \ } g$$
$$\cancel{\Downarrow}$$
$$f_n \cdot g_n \mathop{\longrightarrow}\limits^{\mu \ } f \cdot g$$


Контрпример:

$(\Bbb R, \mathfrak B(\Bbb R), \mu)$ — вещественная прямая со стандартной мерой Лебега


$$f_n(x)=g_n(x)=x+\frac{1}{n} \mathop{\longrightarrow}\limits^{\mu \ } x$$
$$\mu \big( \{x \in \Bbb R: \frac{1}{n} \ge \varepsilon \} \big) \mathop{\longrightarrow}\limits_{n \to \infty} 0$$


Однако, произведение функций $f$ и $g$ не сходится к $x^2$ по мере


$$f_n(x)\cdot g_n(x)=x^2+\frac{2x}{n}+\frac{1}{n^2}$$
$$\mu \big( \{x \in \Bbb R: \Big \lvert x^2 + \frac{2x}{n}+\frac{1}{n^2} - x^2 \Big \lvert \ge \varepsilon \} \big) = \mu \big( \{x \in \Bbb R: \Big \lvert \frac{2x}{n}+\frac{1}{n^2} \Big \lvert \ge \varepsilon \} \big) = +\infty$$


Упс!












#### Два важных примера сходимости по мере

4\.
$f_n \mathop{\longrightarrow}\limits^{\mathcal L^p \ } f$ — сходимость в $\mathcal L^p$

$$\lVert f_n - f \rVert_p = \left( \int_{\mathcal X} \lvert f_n - f\rvert^p \ d\mu \right)^{\frac{1}{p}} \to 0$$


5\.
$f_n \mathop{\longrightarrow}\limits^{\mathcal L^{\infty} \ } f$ — сходимость в $\mathcal L^{\infty}$ или равномерная сходимость почти всюду

$$\lVert f_n - f \rVert_{\infty} = \operatorname*{ess\,sup}_{x \in \mathcal X} | f_n(x) - f(x)| \mathop{\longrightarrow}\limits_{n \to \infty}0$$

где $\operatorname*{ess\,sup}_{x \in \mathcal X}$ — *essential supremum* — это супремум почти всюду

$$\operatorname*{ess\,sup}_{x \in \mathcal X} f = \inf\{M:\ \mu(\{f>M\})=0\} = \inf_{N:\ \mu(N)=0}\ \sup_{x\in \mathcal X \setminus N} f(x)$$



#### Ещё один вид сходимости

3\.
$f_n \rightrightarrows f$ — равномерная сходимость

$$\sup_{x \in \mathcal X} | f_n(x) - f(x)| \mathop{\longrightarrow}\limits_{n \to \infty}0$$
