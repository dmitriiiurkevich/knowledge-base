
### Условие

Сервис работает по подписке с ежемесячными платежами.

```sql
drop table if exists client, payment cascade;

create table client (
    client_id bigint generated always as identity primary key,
    email varchar(360) not null
);

create table payment (
    payment_id bigint generated always as identity primary key,
    payment_time timestamp not null default current_timestamp,
    amount int not null check (amount>0),
    client_id bigint not null references client(client_id)
);
```

Необходимо написать запрос, который вернёт список подписчиков, с которых очередной ежемесячный платёж должен быть списан сегодня.

### Решение


```sql
select email
from client
join payment using(client_id)
where payment_time::date + interval '1 month' = current_date
order by email;
```

Что важно понимать

1\.
Для сдвига даты на 1 месяц необходимо использовать встроенный тип `interval`, а не высчитывать руками: сколько дней было в прошлом месяце: 30 или 31.

2\.
Прибавлять месяц к дате последнего платежа — правильно.
Вычитать месяц из текущей даты — неправильно:
- 28 марта - 1 месяц = 28 февраля ← с этих подписчиков будет списан платёж
- 29 марта - 1 месяц = 28 февраля ← с этих подписчиков — не будет
- 30 марта - 1 месяц = 28 февраля ← с этих подписчиков — не будет
- 31 марта - 1 месяц = 28 февраля ← с этих подписчиков — не будет
